# 0.4.1 Windows Beta：正常流程修复与对抗性复核

本版修复供应商保存、接入修复、独立核验和评测计量的实际流程缺陷。[GitHub Release](https://github.com/Favio8/codexrelay/releases/tag/v0.4.1) 提供 Windows x64 安装包、对应提交源码、脱敏测试证据、许可及 SHA256。本版沿用 schema 5，仍是未签名 Windows Beta。

## 行为变化

- 原样保存、改显示名或重填同一凭据保留供应商修订、证据和价格；实际执行配置变化继续使旧证据失效。
- 后端未安装仅阻止实际后端验证，模型快速响应与工具协议验证可独立执行；HTTP 参数错误、服务异常和网络问题分别提示且不泄露响应正文。
- 新注册的基础能力范围真正限制为基础只读与身份工具；跨运行时自有注册修复显示具体入口变化，并保留归属及外部并发编辑保护。
- 用户可明确选择要核对的聊天，轮询保留选择，重开 App 重新选择；导入报告与实际调用证据保持分离。
- 核验失败不能授予全部／部分通过，历史矛盾记录也不能授权续作。
- 评测界面支持 Pro、推理设置、环境、带来源参考价格、订阅／API 区分，以及失败、未派工和主代理接手登记。
- 正常日志重读和追加幂等；逐请求与累计统计按会话协调，模型切换不重复计量。未知重叠显示下界与缺口。
- 可以明确追加相关子聊天；长日志采用有界流式读取，半条尾行补完后解除临时缺口，真实前缀改写仍保留异常。

## 对抗审查修复

- 供应商保存使用同一事务读取、校验和写入，旧编辑器提交过期修订时明确报错，不能恢复旧凭据引用。
- 供应商工具 ID 回显密钥时过滤该远端标识，成功结果、数据库和快照均不保存回显值。
- 续作在事务内同时核对任务组、最新 Run、checkpoint 和核验记录；迟到证据产生新 checkpoint 后，旧核验不能继续授权执行。
- 任务所属聊天与本次调用聊天分别记录。查询／控制工具可选传入 `client_binding_id`；未提供时保持可用，但不把任务归属冒充调用者身份。客户端类型与已知版本也参与证据匹配。
- 累计用量身份包含绝对计数，避免同时间戳下相同增量被少计；累计响应标签不能导致会话前缀重复计费。
- root、主 session 和相关子 session 共同参与跨试次归属检查。不同试次不能复用同一 root，历史冲突也不会被报告为完整可归属。

主动启用的日常日志缓存会用新版解析器从原日志重建派生记录。旧评测累计记录缺少新版身份元数据时保留缺口，不混入重导数据、不自动抹除历史；建立新试次取得完整依据。

## 验证边界

对抗审查修复 8 项业务及证据缺陷，交付复核另修正侧栏旧版本显示；侧栏与“关于”页共用项目版本。最终全量 **319 项测试通过**（189.895 秒）。另有双后端真实 stdio、同实例跨聊天身份验证、生产前端加 Python RPC、原生 Tauri／WebView2 证据。此前本地实现复核的 298／50 项检查属于历史阶段，不与最终总数相加。该阶段详情见 [实现复核](https://github.com/Favio8/codexrelay/blob/v0.4.1/docs/IMPLEMENTATION-REVIEW.md)；本次对抗审查、最终回归和安装验证结果由附件中的 `adversarial-review.json`、测试日志与 `public-build-verification.json` 记录。

模型请求均使用隔离的本地替身。真实 Codex 六聊天、付费模型质量、真实账单和净收益仍未验证；不宣称节省比例。27 项验收仍为 19 项本地验证、7 项部分验证、1 项真实客户端六场景待执行，具体边界见 [验收矩阵](DELEGATION-ACCEPTANCE.md)。日常配置、委托开关及安装不会因发布操作自动改变。

升级前结束活动委托并核验恢复事项。安装后重新连接 Codex，再检查本聊天的工具与实例。旧实验已有冲突或缺来源元数据时保留旧记录，不以升级清零消耗或自动改判；新试次按 [评测操作说明](DELEGATION-EXPERIMENTS.md) 明确绑定与授权。
