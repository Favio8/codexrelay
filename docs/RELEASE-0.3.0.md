# 0.3.0 本地 Windows 交付

基线为已发布 0.2.2 Windows Beta。本次提供预算来源、有界读取及反馈、两后端统一预请求控制、结构化摘要与上下文段、持久化证据、核验后续作、TaskGroup／独立 Run，以及 App 默认和单任务授权。

源码版本、原生构建和本地安装包为 0.3.0；没有发布远端 Release，也没有替换日常安装。原始 PRD 未修改。具体操作见 [使用与开发合同](EXECUTION-OPTIMIZATION.md)，54 项的实现、验证方法、证据和未覆盖条件见 [验收报告](EXECUTION-ACCEPTANCE.md)。

本地安装包：`src-tauri/target/release/bundle/nsis/CodexRelay_0.3.0_x64-setup.exe`。最终交付副本、SHA256SUMS.txt、源码快照、许可及证据清单位于 `artifacts/releases/0.3.0/`。

验证区分三类证据：固定本地模型响应验证机制与协议；付费模型实验验证特定任务质量；实际 NSIS 与 Tauri/WebView2 验证安装及原生行为。构建通过不替代安装升级，子代理结束不替代父代理验收。

真实模型实验包含 20 次 0.2.2／0.3.0 对照和 7 次分阶段授权补测，总计量受 655,360 Token 上限约束。低预算单行任务仍有未完成样本，思考摘要截断后改为同一模型普通模式，两后端真实上下文重建通过；未证明稳定节省 Token 或所有模型的摘要质量。样本量小、没有预设降幅门槛；费用缺价则未知。

软件保持单外部代理串行；不包含多代理并行、自动唤醒离线 Codex、完整 Pi 编程代理应用或操作系统文件沙箱。取消不回滚。需要人工主代理核验的协议不是对任意可信主机操作的强隔离保证。
