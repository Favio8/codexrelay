# 0.4.0 本地委托可靠性交付验收

日期：2026-10-15（Asia/Shanghai）。本文件记录 0.4.0 Windows Beta 的发布前本地实现与验证。公开交付见 [GitHub Release](https://github.com/Favio8/codexrelay/releases/tag/v0.4.0)；发布不自动执行日常配置修复、日常安装升级或付费模型实验。

发布后的本地实现复核、修复行为与新增证据单独记录在 [IMPLEMENTATION-REVIEW.md](IMPLEMENTATION-REVIEW.md)。下表保留发布基线，不把后续本地改动计入既有发布包。

这些修复及后续对抗审查整改纳入 [0.4.1](RELEASE-0.4.1.md)。新版本额外覆盖并发供应商保存、迟到 checkpoint 证据失效、调用者与任务所有者分离、客户端类型／版本匹配、累计计数碰撞／前缀重叠及跨试次 root 归属；发布附件保留新增测试、原生构建和 0.4.0 隔离升级证据。真实客户端／付费实验的未覆盖状态保持下表口径。

## 交付行为

连接测试完整传递供应商、Flash/Pro、quick/full/backend。快速响应、模型工具协议、实际后端读文件分别保存；供应商修订、模型、推理设置、适配器版本及后端版本区分证据。测试进程有端到端截止、显式取消、有限清理、凭据脱敏和零自动重放；探针单独计量。

MCP 注册与诊断共用版本化能力清单，启动时核对真实注册集合。接入面板分别展示服务端声明、配置推算、客户端报告和实际调用。修复计划可选择基础/完整能力，默认保留拒绝策略和服务器禁用，提供 DPAPI 备份、并发检查和保留后来编辑的恢复流程。应用后仍等待重新连接验证。

任务组、Run、checkpoint 与核验继续沿用既有合同；增加 MCP 实例、显式客户端 session/root、实验与试次关联及不含正文的调用账本。同一个 MCP 进程不能自动视为同一聊天。两个后端的实验请求、摘要、重试和续作共用发送前累计授权门禁。

评测页和本地 CLI 提供五类冻结案例、独立评分、三组隔离试次、显式会话及日志绑定、累计授权预览、请求预留/结算、评分失效和报告。主模型由 Codex 宿主管理，只能观测、提醒，不能拦截其在途请求。API 参考价、订阅和实际账单分开；失败、未派工、接手、负收益及计量缺口都保留。

## 实际验证结果

- 整套单元回归：256 项通过，148.675 秒，无跳过。首轮 239 项出现的 Windows 取消清理错误及其原始日志保留；修复后真实孙进程和目录释放回归通过。
- 最后收紧外部身份未知的收益报告后，受影响的评测模块 31 项再次通过（3.537 秒）；其余已通过且无相关变化的回归不机械重跑。
- 真实 stdio：基础 31 工具、双后端核验续作、GUI 退出/取消/供应商冻结，以及实验绑定/请求门禁/Read-Edit/冻结评分均通过。它们使用本地 HTTP 替身。
- 生产前端/RPC：连接矩阵、接入修复、评测准备、紧凑设置、用量和渲染检查通过。原生 Tauri/WebView2：供应商/凭据/连接/开关、双后端相关路径、App 授权窗口、日志统计和布局通过。
- 本地 TypeScript/Vite、Rust release 构建和 NSIS 打包通过；隔离 0.2.2 与 0.3.1 升级路径通过，最新交付的安装内容核对以 `delivery-verification.json` 为准。

## 真实客户端与付费实验边界

ping 仅证明该入口可调用；配置推算、用户报告和实际调用分别保留。旧版 11 入口限制由隔离 fixture 验证，不能当成每个用户当前的配置。App 自测、CLI stdio fixture、原生 WebView2、真实 Codex 聊天及真实模型测试分别标识，不能互相代替。私有开发机配置、规则指纹、安装路径和客户端实例不进入公开证据包。

使用时先审阅安装产物，在自己的环境生成修复预览，选择性应用；重新连接 Codex；在六个独立新聊天按冻结指令绑定 session/root、执行与核验。另需确定真实主模型、外部供应商/模型/推理设置、费用与 Token 上限、数据目录及停止条件后，才授权模型实验。准备 45 个试次不代表授权运行它们。
