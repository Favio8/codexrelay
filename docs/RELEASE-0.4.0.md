# 0.4.0 Windows Beta：接入可靠性、委托闭环与受控评测

本版增加接入完整性与选择性修复、分层连接验证、客户端/试次证据关联及受控收益评测工具。[GitHub Release](https://github.com/Favio8/codexrelay/releases/tag/v0.4.0) 提供 Windows x64 安装器、发布提交对应的源码、公开脱敏证据、许可、来源清单和 SHA256。仍为未签名 Beta，不自动修改使用者的日常安装或配置。

## 主要变化

- 修复 `test_provider` RPC 丢失模型档位和验证模式：Pro/Flash 与 quick/full 正确传递。快速响应一次请求、模型工具协议正常两次请求、执行后端实际读取随机文件分别验证；有截止、取消、清理、脱敏和零自动重放。
- 能力清单与实际 MCP 注册共用版本化合同。诊断区分服务端声明、配置推算、用户报告和实际调用；名单、拒绝、服务器禁用、旧入口及规则版本各自说明限制。
- 修复预览可选择基础或完整能力，默认保留显式拒绝和其他配置；应用有 DPAPI 备份、并发校验与安全恢复。配置写入后仍等待客户端重新连接验证。
- 沿用任务组、独立 Run、checkpoint 和仅剩余事项续作合同，补显式聊天/root、MCP 实例、实验/试次及调用证据关联。执行结束与独立验收保持分离。
- 修复 Windows 取消时的进程树清理竞态：父进程持有 Job，终止后有界等待全部后代退出，失败不会冒充清理完成。
- 新增五类冻结案例、独立评分、会话/日志绑定、累计授权与请求预留/结算。失败、未派工、接手、负收益、未知缓存费用和缺计量完整保留；主模型仍由宿主管理。
- 评分拒绝候选提前退出与伪造 Run 引用；实际模型/供应商/档位及未知身份不能被当成完整对照。API 参考价格、订阅额度和实际账单分别表达。

## 验证与范围

原始本地整套 **256 项单元测试通过**；最后收紧报告身份门禁后，相关评测模块 **31 项回归通过**。这是两次有重叠的检查，不能相加为 287 个独立测试。公开发布准备另验证许可完整性和脱敏导出。

真实 stdio 枚举 **31 个 MCP 工具**，覆盖双后端 checkpoint/恢复/核验/续作、幂等、生命周期及实验请求门禁。生产前端/真实 Python RPC、原生 Tauri/WebView2、Flash/Pro × quick/full 的实际原生 RPC、双后端文件工具、原生授权窗口及隔离安装升级均有证据。模型响应来自本地确定性服务，这些结果不等于真实 Codex 聊天或真实模型质量。

[27 项验收矩阵](DELEGATION-ACCEPTANCE.md) 中 **19 项本地验证、7 项部分验证、1 项真实客户端六场景尚未执行**。45 试次只准备材料，未授权运行；本轮付费模型实验为零，真实净收益未知。原有版本的真实模型记录不冒充本次新增功能的验证。

## 升级与使用

升级前结束活动委托。安装器沿用原目录并保留供应商、开关、历史和恢复记录；SQLite 迁移到 schema 5，不为历史任务伪造新的客户端或实验身份。

升级后打开「设置与诊断」，检查接入限制，审阅所选能力和托管规则的具体修复预览。应用后重新连接 Codex，在当前聊天核对工具、实例和工作区。单次 ping 或配置保存不代表完整能力已加载。日常总开关继续即时生效；使用者自行决定是否开启。

真实客户端及模型实验的最少人工步骤、六场景和累计额度说明见 [评测操作说明](DELEGATION-EXPERIMENTS.md)。没有明确的模型、限额和数据目录授权，不启动付费实验。

## 公开附件与许可

公开证据保留通过与初始失败记录，但排除真实宿主配置、个人路径和含路径截图；公开副本的索引及引用哈希重新计算，原始本地证据保留。`public-export.json` 解释转换，`release-manifest.json` 关联发布提交、验证快照和最终附件，`SOURCE_MANIFEST.json` 对应 Git 源码包，`BUILD_SOURCE_MANIFEST.json` 区分已测工作区与 Git 文本换行规范化。

公开原生构建映射本机编译路径，分发时移除开发机字节码缓存。补齐精确版本的依赖许可原文、Microsoft WebView2 SDK LICENSE/NOTICE，并提供相关 MPL 组件的原始源码档；来源和校验见 [许可补充](../vendor/licenses/README.md)。这些改动不代替业务测试，也不扩大已验证平台范围。

未覆盖 Windows 10、ARM64、新机器全环境、全部 Codex 构建及组织策略。自动更新、签名和多代理并发不包含在本版本。
