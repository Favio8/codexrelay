# 0.2.1 本地修复版本

日期：2026-10-13（Asia/Shanghai）。本次提供本地 Windows 安装包，尚未发布 GitHub Release。

修复启动读取时不必要的数据库写锁：数据库结构按版本原子初始化，已初始化的数据库不重复建表；空闲状态快照使用一致的只读事务，存在活动任务时仍保留原子回收。已复现旧版读取会等待其他写入事务，新版空闲读取可直接返回最近已提交的数据。原截图未保留 SQLite 具体错误码，因此该验证不证明截图错误只有这一种成因。

数据库占用、权限和运行时异常使用不同提示，详情仅返回异常类型和 SQLite 错误码。前端仅对明确的数据库占用读取进行有限重试，保存设置和模型测试不重放。自动刷新避免同类请求重叠；成功后清除对应过期错误，手动关闭相同错误后不重复展示。操作失败和其他读取错误各自保留。

总览供应商名称调整为 18px，“已导入”作为小标签展示，不修改已保存名称。执行后端面板保留选择、应用与测试操作，说明默认折叠，测试模型选择框与按钮统一为 38px 高度。

验证：119 项单元测试通过；TypeScript/Vite 构建通过；24 个工具的真实 stdio MCP 回归通过；浏览器与真实 Python RPC 验证 900/800 宽度布局、提示恢复与关闭、保存和测试不重试；真实 Tauri/WebView2 与 bundled Python/Pi 验证本地模型与 Read 往返、设置保存、日志与价格、托管规则和窗口布局。

安装包：`src-tauri/target/release/bundle/nsis/CodexRelay_0.2.1_x64-setup.exe`。测试使用隔离配置及本地模型接口。当前日常安装与 Codex 接入配置未替换；安装包升级后生效。
