# 委托用量 MVP 实施记录

日期：2026-10-13（Asia/Shanghai）。本页记录 U1 初次交付。后续 U2 和多后端现已纳入 0.2.0，详见 [完整交付记录](ROADMAP-0.2.0.md)。本机安装已升级，最终收尾与验证见 [0.2.0 交付记录](RELEASE-0.2.0.md)。GitHub 安装包 Release 尚未发布。

## 用户可用功能

- 总览新增“今日委托用量”，包含所有项目当天结束的任务；完成、失败、停止、中断均统计已取得的供应商用量。
- 明细分开显示输入/输出、任务结果、主代理复验、缺失及部分用量、估算费用和等量 Token 价格差。
- 从明细或“设置与诊断 → 用量与价格”填写人民币输入、输出及可选缓存命中单价；参考模型独立设置，可关闭对比。
- 新任务保存供应商版本、实际模型和价格快照；调价或删除供应商不会改写已有任务费用。历史未计价任务可以明确应用已保存价格，标记“回填估算”。
- 统计覆盖全部匹配任务；明细只展示最近 50 条，并可打开原任务。用量查询不依赖 snapshot 的最近 100 条限制。

## 统计口径

按本机系统时区、任务 finished_at 归日。跨日任务的全部已知用量归入结束当天；意外退出按发现中断时间近似归属。运行中任务另列、不计入已结算数。

优先 telemetry.tokens，旧任务回退 result.tokens，同一任务只取一次。供应商没有返回用量时显示未知；本地预算计量不参与费用计算。未计价、未返回、部分和历史覆盖未知分别显示。

金额使用 Decimal 计算，以 CNY／百万 token 配置。缓存比例未知且存在缓存差价时显示区间；统一输入价需由用户明确填写。等量价差允许负值，不声称为实际账单或真实节省，不计入未观测的主代理监工及返工。

仅覆盖保留的委托记录，不含连接测试及该供应商账户的其他消费。U1 不读取 Codex 会话日志、不请求实时价格、不新增网络调用。

## 实现

- `engine/codexrelay/usage.py`：任务归一化、日期范围、全量只读聚合、十进制计算、价格配置与显式回填。
- `state.py`：接收事务内冻结价格；任务接收/终态/复验/中断回收更新 usage_revision。中间工具事件不触发用量重算。
- `service.py`：usage_today、get_usage_prices、save_usage_price、backfill_usage_price、get_task RPC。
- `desktop/UsagePanel.tsx`：卡片、明细、价格编辑、60 秒前端缓存；按数据目录、日期/时区和 revision 失效，并支持手动刷新、聚焦及日界检查。
- SQLite 沿用 settings/tasks 的 JSON 字段，不引入迁移框架、常驻统计服务或新依赖。不改变供应商 Key 保存和执行路径。

Rust 每次 RPC 启动一个 Python 进程，因此缓存放在前端模块而非 Python 全局变量中。价格更改及终态更新的 revision 随既有 snapshot 传递，只触发独立用量查询。

## 验证

- 67 项全量单元测试通过，其中 12 项用量测试覆盖金额算例、负价差、缓存区间、所有终态、旧数据、价格冻结/回填、时区边界及 revision。
- 10,001 条任务聚合约 0.11–0.12 秒（本机 Windows 开发环境）；包含坏 JSON 记录时仍返回有效汇总和覆盖提示。
- 现有真实 stdio MCP 回归通过：12 个工具、文件读取/写入、恢复确认、开关与取消；模型端为本地确定性替身，无付费请求。
- TypeScript 检查及 Vite 生产构建通过。
- `tests/usage-ui.mjs` 使用生产前端、900 × 600 Chromium 窗口和真实按次 Python RPC，数据位于独立 `.tmp/usage-ui-*`。验证价格设置、回填、9.70 价差、失败任务消耗、缓存、终态失效及历史详情跳转。
- 界面已检查横向溢出、弹层滚动及切换视图回到顶部；这不是新的原生 Tauri/WebView2 或安装包验收。

复现：

```powershell
runtime/python.exe -I -B -X utf8 -m unittest discover -s tests -p test_usage.py -v
npm run build
node tests/usage-ui.mjs
```

UI 测试使用本机已安装 Chrome。截图与机器可读结果位于 `artifacts/evidence/usage-overview.png`、`usage-details.png`、`usage-ui.json`（忽略目录）。日界定时刷新与聚焦刷新已实现；后台时钟推进未做独立浏览器模拟。费用不完整性不影响开关和取消。
